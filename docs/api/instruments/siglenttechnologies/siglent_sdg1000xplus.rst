#########################################
Siglent SDG1000X Plus Waveform Generator
#########################################

Two-channel function/arbitrary waveform generator with 16-bit DAC,
1 GSa/s sample rate, and 8 Mpts of arbitrary waveform memory per channel.
Available SKUs are SDG1022X Plus (25 MHz), SDG1032X Plus (30 MHz), and
SDG1062X Plus (60 MHz). PRBS, multi-pulse, sequence playback, and the
built-in web server are not yet exposed by this driver.

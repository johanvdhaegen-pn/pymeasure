####################################
Siglent SDG2000X Waveform Generator
####################################

Two-channel function/arbitrary waveform generator with 16-bit DAC,
1.2 GSa/s sample rate, and 8 Mpts of arbitrary waveform memory per
channel. Available SKUs are SDG2042X (40 MHz sine), SDG2082X (80 MHz),
and SDG2122X (120 MHz).
